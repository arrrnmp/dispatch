Surface Colors — Dark Mode
Surfaces invert: surface-0 becomes #0a0c10, surface-5 becomes #f0f2f4. Defined in prefers-color-scheme: dark media query.
Usage Guidelines
surface-0 — Primary Backgrounds
Main page backgrounds, cards, modals. Always white in light mode.
surface-1 — Soft Backgrounds
Alternating sections, hover states, subtle separation. Cool gray tint.
surface-2 — Secondary Surfaces
Input backgrounds, disabled states, secondary containers.
surface-3 — Dividers & Borders
Strong borders, active backgrounds, emphasized containers.
surface-4 — Dark Surfaces
Footers, contrast sections, dark mode primary surfaces.
surface-5 — Deepest Dark
Near-black for maximum contrast. Used sparingly.
